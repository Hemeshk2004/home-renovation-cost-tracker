Firebase not connecting?

This page needs two things enabled in the Firebase project it points to:

  1. In Firebase Console → Authentication → Sign-in method, enable Anonymous sign-in.
  2. In Firebase Console → Firestore Database, create a database (if not already created) and set rules to allow reads/writes, e.g. for a private family tracker: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /renovation/{doc} {
      allow read, write: if request.auth != null;
    }
  }
}

Until that's fixed, the app keeps working fully offline using your browser's local storage — nothing is lost, it just won't sync between devices yet.
